# BongoBro

Мультяшный человечек за клавиатурой в духе Bongo Cat: сидит поверх окон и стучит по клавишам вместе с тобой.

- Реагирует на клавиатуру и мышь, считает нажатия.
- Каждые 2000 нажатий даёт лутбокс; из лутбоксов выпадают шапки, очки, перчатки, выражения лица и стили клавиатуры (common / rare / legendary / immortal).
- 10 достижений, за самые сложные — золотой лутбокс только с immortal.
- Два персонажа: Юра и Влад (арбуз), переключаются в меню или в гардеробе.
- Лидерборд по нажатиям клавиш, пересчитывается каждые 12 часов (участие по желанию: нужно задать ник).
- Обновляется сам: в меню появляется «Обновить до версии …».

## Установка

1. Скачай [BongoBro.exe](https://github.com/PanteraGS/BongoBro/releases/latest/download/BongoBro.exe).
2. Положи его в постоянную папку (например, «Документы\BongoBro»), а не в «Загрузки».
3. Запусти. Если Windows покажет «Система Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае»: программа не подписана сертификатом.

Нужен Windows 10/11 (.NET Framework 4.8 уже встроен). Правый клик по персонажу открывает меню: гардероб, достижения, размер, автозапуск.

Прогресс хранится в `%APPDATA%\BongoBro\save.dat` и не теряется при обновлении.

## Сборка

```powershell
powershell -File build.ps1
```

Собирается компилятором C#, который уже есть в Windows (`csc.exe` из .NET Framework 4).

## Выпуск обновления

```powershell
powershell -File release.ps1 -Version 1.1.0 -Notes "Что изменилось"
```

Скрипт проставит версию, соберёт exe, сделает коммит и тег и выложит релиз на GitHub. Программы у пользователей увидят его при следующей проверке (при запуске и раз в 6 часов).

## Лидерборд (папка `server`)

Cloudflare Worker + база D1. Программа раз в час отправляет ник, персонажа и число нажатий; cron в 00:00 и 12:00 UTC публикует снимок таблицы. Строку игрока может обновить только владелец секретного токена из его сохранения.

```powershell
cd server
npm install
npx wrangler deploy
```

## Совместимость сохранений

ID предметов (`hat_crown`, `th_rgb`, …) и достижений (`ach_keys1k`, …) записываются в файл сохранения. Существующие ID нельзя переименовывать или удалять — добавлять новые можно спокойно.
